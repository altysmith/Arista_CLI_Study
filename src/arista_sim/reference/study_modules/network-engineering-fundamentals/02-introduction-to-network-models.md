# 2. Introduction to Network Models

**Official unit:** Network Engineering Fundamentals → Network Introduction

# Learn

A network model standardizes how devices send and receive information, both hop-by-hop and end-to-end. OSI means Open Systems Interconnection; “open” supports communication across vendors.

| Layer | Name |
|---:|---|
| 7 | Application |
| 6 | Presentation |
| 5 | Session |
| 4 | Transport |
| 3 | Network |
| 2 | Data Link |
| 1 | Physical |

# Flashcards

**What does OSI stand for?** Open Systems Interconnection.  
**Why is “open” important?** It provides a cross-vendor standard.
