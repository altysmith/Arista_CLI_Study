# 4. Wireshark and TCP-IP

**Official unit:** Network Engineering Fundamentals → Network Introduction

# Learn

Wireshark is a packet-capture tool. The TCP/IP model maps to OSI as follows:

| TCP/IP | OSI |
|---|---|
| Application | 5–7 |
| Transport | 4 |
| Internet | 3 |
| Network Access | 1–2 |

# Flashcards

**Which TCP/IP layer maps to OSI 5–7?** Application.  
**Which maps to OSI 1–2?** Network Access.
