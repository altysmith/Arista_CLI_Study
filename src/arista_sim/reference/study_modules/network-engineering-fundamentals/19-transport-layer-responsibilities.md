# 19. Transport Layer Responsibilities

**Official unit:** Network Engineering Fundamentals → Transport and Application Layer

# Learn

Layer 4 identifies the application conversation using ports. Its responsibilities include connection establishment, segmentation, sequencing, retransmission, and receive flow control. Layer 4 information includes source port, destination port, and sequence number.

```text
MAC → local delivery
IP → host/network delivery
TCP/UDP port → application/service conversation
```
