# 9. Introduction to IPv4

**Official unit:** Network Engineering Fundamentals → Network Layer

# Learn

IPv4 operates at OSI Layer 3 and provides end-to-end addressing from one source IP to one destination IP.

# Flashcards

**IPv4 layer?** Layer 3.  
**Address roles?** Source and destination IP.
