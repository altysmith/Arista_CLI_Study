# 7. Ethernet and MAC Addressing

**Official unit:** Network Engineering Fundamentals → Data Link Layer

# Learn

The notes describe LAN as same-building, MAN as one ISP between two LANs, and WAN as multiple ISPs between LANs. LANs contain endpoints, switches/APs, and copper/fiber.

802.3 is wired Ethernet; 802.11 is Wi-Fi. A MAC address is a 48-bit, 12-hex-character, 6-byte physical address. The first three bytes are the vendor OUI and the last three are device-specific. Source and destination MAC addresses appear in the Layer 2 header and guide switching.

# Flashcards

**MAC length?** 48 bits / 12 hex characters / 6 bytes.  
**What is the OUI?** The first three bytes identifying the vendor.
