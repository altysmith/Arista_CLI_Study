# 15. LAB — Configure IPv6 Addresses

# Lab Goal

Configure and verify IPv6 global and link-local connectivity.

# Tasks

1. Assign `/64` global addresses to routed interfaces.
2. Inspect or configure link-local addresses.
3. Verify interfaces and IPv6 routes.
4. Ping directly connected global and link-local neighbors.
5. Use NDP information to confirm neighbor discovery.
6. Introduce and correct one prefix or compression error.

# Success Criteria

- [ ] Correct global and link-local addresses are active.
- [ ] Connected IPv6 routes and neighbors appear.
- [ ] IPv6 pings succeed.
