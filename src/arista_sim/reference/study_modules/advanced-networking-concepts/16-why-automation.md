# 16. Why Automation

# Learn

Manual networking becomes difficult as configurations, device count, monitoring, maintenance, and change control scale. Repetitive CLI work reduces agility and increases inconsistency.

Modern automation should centralize deployment and configuration generation, aggregate telemetry for troubleshooting, provision new switches automatically, and provide one integration point for external services.
