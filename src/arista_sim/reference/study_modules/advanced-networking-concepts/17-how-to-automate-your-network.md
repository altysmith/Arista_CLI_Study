# 17. How to Automate Your Network

# Learn

Arista devices can be configured through CLI, scripts such as Python-generated CLI, or CloudVision. Automation maturity ranges from copy/paste, to supplemental scripts, to centralized configuration management and generation.

CloudVision provides GUI-based configuration, state, and telemetry. Templates translate intended input into configuration. CI/CD pipelines test changes before deployment; the notes summarize AVD as Architect, Validate, Deploy.
