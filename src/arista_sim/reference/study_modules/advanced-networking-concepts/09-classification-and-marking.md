# 9. Classification and Marking

# Learn

Classification identifies traffic using ACLs, VLANs, ports, protocols, or application recognition. Marking records a classification so downstream devices do not repeat it.

CoS is a 3-bit Layer 2 marking with values 0–7. IP precedence uses the first 3 ToS bits. DSCP uses 6 bits with values 0–63. The trust boundary is the first device whose markings the organization trusts.
