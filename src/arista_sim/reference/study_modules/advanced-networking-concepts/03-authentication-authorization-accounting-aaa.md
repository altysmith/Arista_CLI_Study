# 3. Authentication, Authorization, Accounting (AAA)

# Learn

Authentication asks who you are, authorization what you may do, and accounting what you did. AAA centralizes administrative and 802.1X user control.

RADIUS uses UDP 1645/1812 for authentication and 1646/1813 for accounting, commonly for network access. TACACS+ uses TCP 49, separates authentication and authorization, supports command logging and SSO, and is commonly used for administrative access.
