# 6. LAB — Access Lists

# Lab Goal

Build, apply, and verify ACLs that enforce stated policy.

# Tasks

1. Translate policy into ordered permit/deny statements.
2. Choose standard, IP, or MAC ACL.
3. Place specific entries before general entries.
4. Apply the ACL on the correct interface and direction.
5. Test permitted and denied flows.
6. Verify counters/configuration and document implicit-deny behavior.

# Success Criteria

- [ ] Intended flows pass and prohibited flows fail.
- [ ] Unrelated traffic is not accidentally blocked.
