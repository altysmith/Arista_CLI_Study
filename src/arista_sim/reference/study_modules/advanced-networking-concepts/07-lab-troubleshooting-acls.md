# 7. LAB — Troubleshooting ACLs

# Lab Goal

Locate and repair ACL policy, order, placement, and direction faults.

# Tasks

1. Reproduce the failed flow and define source, destination, protocol, and port.
2. Identify the applied ACL and direction.
3. Walk rules top-down to the first match.
4. Check prefix specificity and implicit deny.
5. Correct one ordering fault and one interface/direction fault.
6. Retest both intended and regression flows.

# Success Criteria

- [ ] Root cause is documented.
- [ ] Minimal correction restores only intended traffic.
