# 5. LAB — Configure Static Routing

# Lab Goal

Establish end-to-end reachability using static routes.

# Tasks

1. Verify all connected routes.
2. Add each remote LAN using an exit interface or next hop.
3. Add required return routes.
4. Verify `S` entries.
5. Test LAN-to-LAN reachability.
6. Replace a specific route with a default route where appropriate.
7. Troubleshoot one missing or incorrect next hop.

# Success Criteria

- [ ] Forward and return paths exist.
- [ ] Remote pings succeed.
- [ ] Route-table entries match the design.
