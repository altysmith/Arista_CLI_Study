# 12. LAB — Configure Routing Protocols

# Lab Goal

Configure and compare a distance-vector protocol and a link-state protocol.

# Tasks

1. Verify connected interfaces and routes.
2. Enable the selected routing protocol on intended networks.
3. Verify learned routes and next hops.
4. For OSPF, verify neighbors with `show ip ospf neighbor`.
5. Test end-to-end connectivity.
6. Fail one routed link and observe reconvergence.
7. Compare route source, metric, and convergence behavior.

# Success Criteria

- [ ] Neighbors form where expected.
- [ ] Remote routes appear.
- [ ] Traffic recovers through the alternate path.
