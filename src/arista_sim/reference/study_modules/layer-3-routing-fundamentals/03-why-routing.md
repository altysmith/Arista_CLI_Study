# 3. Why Routing

# Learn

A directly connected network has a router interface on it and appears automatically as `C`. A remote network has another Layer 3 device between it and the router and must be learned through static or dynamic routing.

Point-to-point routed links commonly use `/30`, providing two usable addresses.
