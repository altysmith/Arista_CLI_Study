# 6. Dynamic Routing

# Learn

Static routing is manual, does not adapt automatically, and ignores alternative-path metrics. Dynamic protocols exchange network information, select best paths, and fail over.

A metric measures a path. IGPs operate inside an autonomous system; EGPs operate between autonomous systems. The notes categorize RIP/IGRP as distance vector, RIPv2/EIGRP as advanced distance vector, OSPF/IS-IS as link state, and BGP as the EGP.
