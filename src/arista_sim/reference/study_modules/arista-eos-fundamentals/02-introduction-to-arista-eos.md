# 2. Introduction to Arista EOS

# Learn

EOS means Extensible Operating System. It runs on a Linux kernel and Arista hardware, exposes underlying Linux capabilities, and supports Python and third-party integration.

Form factors include hardware EOS, vEOS in a VM, and cEOS in a container. Devices can be configured through CLI, CloudVision GUI, or APIs.
