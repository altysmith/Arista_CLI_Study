# 10. CLI Configuration Modes

# Learn

EOS CLI moves through user EXEC, privileged EXEC, global configuration, and feature/interface submodes. `enable` enters privileged mode, `configure terminal` enters global configuration, `exit` moves back one level, and `end` returns to privileged EXEC.

Prompts show context, such as `Switch#`, `Switch(config)#`, and `Switch(config-if-Et1)#`.
