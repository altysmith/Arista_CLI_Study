# 4. Introduction to Network Database (NetDB)

# Learn

NetDB extends network-state handling beyond one device. Remote replication efficiently transmits switch state. NetDB Central stores large amounts of network data in a central repository such as CloudVision infrastructure.

NetDB Net Table supports large routing scale and fast convergence.
