# 8. Connect to Network Devices

# Learn

Network devices can be reached locally through console access or remotely through management connectivity. Console access does not depend on working IP service; remote access requires addressing, routing, and an enabled management service.

Out-of-band management uses a dedicated management interface/network, preserving access when the production network fails. In-band management shares production paths.
