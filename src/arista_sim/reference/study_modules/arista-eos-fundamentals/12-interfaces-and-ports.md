# 12. Interfaces and Ports

# Learn

Enter interface context with `interface ethernet <number>` or configure a range. Interface configuration includes descriptions, shutdown state, Layer 2 access/trunk behavior, Layer 3 addressing, speed/duplex where applicable, and logical Port-Channels or SVIs.

Useful checks include `show interfaces status`, `show ip interface brief`, interface counters, and interface-specific running configuration.
