# 5. EOS Network Data Lake (NetDL)

# Learn

NetDL collects state from multiple types of network devices for analytics and machine learning. The notes associate it with AVA capabilities including network detection and response, wireless intrusion prevention, quality monitoring, anomaly detection, utilization forecasting, and failure prediction.

An API layer integrates external services, and CloudVision provides the operational platform.
