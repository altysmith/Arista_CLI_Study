# 15. LAB — Introduction to EOS CLI

# Lab Goal

Navigate EOS, inspect state, make a safe basic change, and verify persistence.

# Tasks

1. Move through EXEC and configuration modes.
2. Use help and command completion.
3. Inspect running and startup configuration.
4. Set hostname and an interface description.
5. Verify only the intended lines changed.
6. Save configuration and confirm persistence.
7. Use filtered show output to locate configuration efficiently.

# Success Criteria

- [ ] Correct mode and prompt used for each task.
- [ ] Changes are verified and saved.
- [ ] No unrelated configuration changed.
