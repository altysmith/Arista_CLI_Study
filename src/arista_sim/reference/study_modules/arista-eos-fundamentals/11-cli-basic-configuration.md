# 11. CLI Basic Configuration

# Learn

Basic EOS work includes setting identity, entering feature submodes, inspecting running state, and saving intended changes. Use `show running-config` for active nondefault configuration and `show running-config all` when defaults matter.

Use command help, abbreviations carefully, and narrow output rather than scrolling through unrelated configuration. Save configuration after verification so it survives reboot.
