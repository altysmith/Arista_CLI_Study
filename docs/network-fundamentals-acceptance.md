# Network Engineering Fundamentals acceptance checklist

This checklist covers the first authoritative Google Drive curriculum section.

- [x] All 20 numbered modules are present in `00-curriculum-map.md` order.
- [x] Every module is directly selectable; sequential unlocking is not required.
- [x] Learn content is rendered from the source Markdown without rewriting it.
- [x] Markdown headings, lists, tables, fenced code, inline code, and emphasis render semantically.
- [x] Flashcard answers are hidden until individually revealed.
- [x] Knowledge Quiz questions begin without visible answers.
- [x] Learners write an answer, compare it with the source Learn content, and mark it correct or retry it; blank answers cannot be marked correct.
- [x] Practical Exercises retain the supplied task, optional notes, and a separate completion state.
- [x] Mastery Check items are individually checkable and stored separately.
- [x] Learn, Flashcards, Quiz, Practical Exercise, and Mastery progress are tracked separately for every module.
- [x] Opening a module does not mark any activity complete or master the module.
- [x] Progress persists in the existing server-side SQLite database without changing saved lab-session records.
- [x] Previous and next navigation is available, including the section endpoints.
- [x] Search matches lesson titles and full source content and opens the matching module.
- [x] Section and module progress are visible.
- [x] Lessons and labs remain visibly distinguishable in the shared curriculum navigator.
- [x] Desktop browser review completed.
- [x] Phone-size browser review completed at 390 × 844.
- [x] Keyboard-accessible semantic buttons, text fields, checkboxes, headings, tables, and focusable disclosures are used.
- [x] `/health` and `/version` expose non-sensitive build metadata; the same metadata appears in the interface.
- [x] Automated integrity, persistence, HTTP, JavaScript syntax, and regression checks pass.
